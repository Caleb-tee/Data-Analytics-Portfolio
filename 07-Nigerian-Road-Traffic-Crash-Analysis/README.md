#  Nigerian Road Traffic Crash Analysis

##  Project Overview

This project analysed road traffic crash data to identify crash trends, leading causes, regional patterns, and seasonal variations.

---

##  Business Problem

Support road safety initiatives through evidence-based analysis.

---

##  Tools Used

- Microsoft Excel
- PivotTables
- Dashboard

---

##  Data Cleaning & Preparation

- Standardised state names.
- Corrected formatting.
- Validated crash records.

---

##  Analysis

Crash frequency, fatalities, injuries, vehicles involved, and crash causes were analysed across states and time periods.

##  Key Insights

- Speed violations caused the highest number of crashes.
- Some states consistently recorded higher crash rates.
- Weather-related crashes were comparatively rare.

---

##  Recommendations

- Increase speed enforcement.
- Improve road safety education.
- Focus interventions on high-risk states.
